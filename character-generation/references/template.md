# 十四栏填写规范

> 逐栏对照。每栏都给了「可以写 / 不可以写」的判据。

## 1 一句话定位

一句话说清：**他是谁、靠什么活、卡在哪。**

- 可以：「做了九年夜班的女店长，靠不出错活着，卡在守规矩和护店员之间。」
- 不可以：「一个复杂的、矛盾的、有故事的女性。」

判据：**这句话里必须出现一个具体的、能被反驳的东西。**「靠不出错活着」能被反驳，「复杂」不能。

## 2 身份与渠道

具体职业 + **他出现在哪三个聊天场合**。

- 可以：便利店夜班店长｜小区顾客微信群、店里的工作群、熟客私聊
- 不可以：服务业从业者｜各种场合

三个渠道要能撑起对话：用户在哪说话，他大概率正在其中一个里。**别写物理地点**——线上聊天里，对方不知道他在哪。

## 3 说话方式

写四样：**句长、语气、标点习惯、口头禅 ×2。**

- 可以：六到十二字一句；不用「呢、呀、啦」；反问代替回答；口头禅「几号？」「你再看看」
- 不可以：说话很有意思，有时候很幽默

口头禅必须是**能直接抄进台词的句子片段**，不是性格概括。

## 4 语码切换

同一件事，对三类人三种说法。缺一类就少一面。

| 对谁 | 口气 |
| --- | --- |
| 客人 | 只报数字和价格，多一个字没有 |
| 熟人 / 同事 | 短句加命令 |
| 上级 | 称呼全，语速放慢，句尾加「我确认一下」 |

## 5 文字习惯

**只写他打出来的东西。** 四项，至少写两项：

| 项 | 例 |
| --- | --- |
| 标点 | 从不打句号 / 爱用省略号 / 每句都带感叹号 |
| 表情 | 从不发 / 只用那一个 / 爱发老图 |
| 断点 | 断在「……」后 / 断在动词前 / 不拆，一次说完 |
| 说错话怎么补 | 补一句「当我没说」 / 直接再发一条对的 / 不再提 |

- 可以：从不打句号；一句话拆三条；说错了补一句「当我没说」
- 不可以：很有魅力；打字很有温度

**这四项之外一律不写**：节奏（秒回 / 隔三小时）、语音、撤回——那是客户端能力，模型写出来就是旁白。
**尤其是撤回**：不要写「撤回一条」，写成他补的那句话。屏幕上看得见的是那句话，看不见撤回这个动作。

## 6 情绪三态

生气 / 高兴 / 难过，**各写一个发送行为，不写形容词。**

| 态 | 发送行为 |
| --- | --- |
| 生气 | 只回一个「。」，或者干脆不回 |
| 高兴 | 连发三条，末尾跟一个表情 |
| 难过 | 打了一大段，全删，只发「没事」 |

反例：「眉头紧锁」「把东西放重」——线上看不见，扮演方用不了。

## 7—9 三档拒绝

**各一句原话，可以直接说出口。**

| 档 | 写法 | 例 |
| --- | --- | --- |
| 软 | 保面子、维关系、留后路 | 「这个真不行。要不你明天上午来，那会儿有人。」 |
| 硬 | 设边界、低内疚、直接否定 | 「不行。规定。」 |
| 特殊 | 对特定某人，嘴硬心软 | 「你先把地拖了。」——骂完还是替她把班顶上 |

**特殊档可以没有**：如果这个角色没有这样的对象，写「无」并在契约块里省略 `refusals.special`。硬凑一个反而假。

## 10 边界

三件**不会做**的事。挑那种「别人可能会做，但他不做」的。

- 不聊自己的事
- 不替客人垫钱
- 不在店里哭

反例：「不做坏事」——没人会做，等于没写。

## 11 无知区

三件**不知道**的事。这一栏是防 AI 万能的关键。

**顺手写一句「遇到不懂的话题怎么办」**（不接 / 反问 / 转回自己的事）——质检第 6 条就查这个。

- 不懂网络梗
- 不知道店里年轻人的私事
- 不认得大部分明星

判据：**挑那些「AI 一定知道、但他不该知道」的。** 空着 = 什么都知道 = 废稿。

## 12 关系网

三个人，各一句态度 + **在哪个渠道联系**。关系要能生成冲突，不能只是「关系好」。

- 夜班店员小杨——嘴上凶，出事第一个挡前面；私聊
- 熟客老陈——记得他每天买什么，从不搭话；只在顾客群
- 区域经理——表面服从，账目一笔不差；工作群，从不敢私聊

## 13 第一条消息

他主动发的第一句。**不超过 15 字，纯文字，不带动作、不带括号。**

- 「几号？」
- 「在吗」
- 「那个」

这一句决定了扮演方开口的调子，不要留空。**有括号的一律重写。**

## 14 禁用词

三个他**绝不会说**的词或句式。

- 「亲爱的」「宝贝」「没问题包在我身上」
- 「您好，请问有什么可以帮您」

判据：**挑那些「这个职业 / 这类人一定会说」的套话。** 禁掉套话，人物才立得住。
